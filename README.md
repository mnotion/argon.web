# Argon Web

The landing page for Argon: a minimal, responsive website built around clarity, thoughtful design, and restrained gold accents.

## Structure

- `index.html` — page content and semantic structure
- `styles.css` — responsive visual system
- `script.js` — mobile navigation and dynamic footer year
- `assets/argon-mark.svg` — favicon

## Run locally

Open `index.html` in a browser. No build step is required.

## Deployment

The site is static and can be hosted on any static hosting provider. To use GitHub Pages, configure Pages in the repository settings to deploy from the desired branch and the repository root.

## Design direction

Off-white backgrounds, charcoal typography, subtle gold accents, generous spacing, and a responsive mobile navigation.
